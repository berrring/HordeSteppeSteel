# Checkpoint 1 individual defense guide

Open the standalone place and press **Play**. Each teammate should explain an actual function and ask a different teammate to perform the demonstration, then record the result in the manual test document.

| Student | Walkthrough | Explain one function | Demonstrate | Likely question and answer |
| --- | --- | --- | --- | --- |
| Aziret | `GameManager.server.luau` receives commands, `Match.luau` owns state, and Renderer updates from it. | `installMatch` assigns a new campaign ID, rebuilds the world and sets the authoritative match. Subsequent orders must carry that ID and the current turn. | Start twice in one session and compare 12 provinces, five armies and a new match ID. | How is overlapping End Turn prevented? The server holds a busy flag across the command and the timed Rus phase. |
| Ayaz | `Match.luau` calculates income, the server returns a state snapshot and `CampaignHud.luau` displays it. | `Match.income` aggregates yields for owned provinces. The turn setup applies economy rules on the server, and HUD redraw follows the response. | Compare starting 34/27/22 resources to 42/35/25 after capturing Kiev and ending the turn. Inspect the visible per-turn yields. | Can the client submit a gold value? The command schema rejects unexpected fields and the server computes gold itself. |
| Iskender | `Match.luau` resolves encounters and `AI.luau` makes decisions during the server's Rus phase. | `AI.checkpoint` evaluates candidate legal orders using board rules and applies the chosen moves or attacks through Match. | Capture Kiev with the Sarai archer and watch Moscow respond after End Turn. | What gives you Kiev? If the defender is removed and the attacker survives, Match applies the advance and changes the province owner. |
| Alen | `Provinces.luau` defines topology, `Renderer.luau` builds the world, `CampaignArt.luau` adapts the library, and `CameraController.luau` frames the board. | `R:reset` replaces the previous world, places provinces by shared coordinates, and draws roads from the same edges the server validates. | Point out river crossings, Sarai's ger and the Rus halls, then zoom and select an army via its model. | Why do some versions look different from the gallery? The gallery's opaque geometry does not survive rendering from the reopened place. The campaign uses anchored native replacements where needed. |
