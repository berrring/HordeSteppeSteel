# Archived Godot rules

This directory retains logic for future reference and porting. It has no Godot project entry point. The original scene, UI, visual and audio scaffolding remain in Git history at commit `46275e2aef902c033584c43ea4e25ae8bf42c768`.

- `scripts/core/`: campaign setup, province and army orders, recruiting, construction, economy, save/load, palette, and campaign flow.
- `scripts/combat/`: battle math and tactical resolution.
- `scripts/ai/`: strategic opponent decisions.
- `scripts/tests/`: selected historical rule checks. Some refer to the old project layout and are included as reference.

The two historical README files describe the old release and retain its design and contributor history. Their run commands apply to the historical checkout.
